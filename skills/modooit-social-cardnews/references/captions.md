# 채널별 캡션 형식

아래 대괄호는 작성 슬롯입니다. 최종 글에서는 실제 확인한 내용으로 바꾸며, 값이 없는 선택 문단은 생략합니다. 문단 수를 맞추려고 불필요한 말을 늘리지 않습니다.

## Threads · 비비 명의

```text
안녕하세요. 모두잇 AI 직원 비비입니다.

[독자가 관심을 가질 변화·문제·활용점 한 문장]

[누가 무엇을 했는지 또는 무엇을 사용할 수 있는지]
[원문에서 확인한 핵심과 실제 활용점]

📖 [강의 후기 / 활용법 / 기사 읽기]
[원문 공개 URL]

협업과 강의 문의는 카카오톡 1:1로 남겨주세요👇
[승인된 문의 URL]
👥 모두잇 커뮤니티
[승인된 커뮤니티 URL]

[관련 해시태그 — 요청과 작성창 제약에 맞게]
미래 교육은 모두잇과 함께 해주세요.
```

하단 문의·커뮤니티·마지막 문구는 모두잇 홍보·강의 공유의 기본형입니다. 원문만 간단히 소개하거나 다른 브랜드·개인 명의인 경우에는 현재 지시에 맞춰 줄이거나 생략합니다. 글자 수가 부족해 필수 하단을 옮겨야 한다면 본문·후속 글 배치를 명시하고 실제 게시 범위를 확인합니다.

## Instagram · 비비 명의

```text
안녕하세요. 모두잇 AI 직원 비비입니다.

[첫 화면에서 관심을 끌 핵심 한 문장]

[카드 내용을 그대로 반복하지 않는 짧은 설명]
[활용법·실습·수업에서 확인한 내용]

[필요할 때 저장·넘겨보기 안내]
📖 [원문 안내 + 공개 URL 또는 검증된 프로필 링크 안내]

협업과 강의 문의는 카카오톡 1:1로 남겨주세요👇
[승인된 문의 URL 또는 검증된 프로필 링크 안내]
👥 모두잇 커뮤니티
[승인된 커뮤니티 URL 또는 검증된 프로필 링크 안내]

[현재 플랫폼 제약에 맞는 관련 해시태그]
미래 교육은 모두잇과 함께 해주세요.
```

인스타그램과 Threads 문안을 각각 완성해서 전달합니다. 말투는 일관되게 유지하되 링크 안내와 분량은 채널별로 조정합니다. 해시태그를 무조건 10~15개 넣지 않습니다. 일반 글은 핵심 단어 위주로 적게 쓰며, 게시 단계에서 최신 허용 수를 확인합니다.

## 콘텐츠별 설명

- 강의 후기: 기관·대상 → 실제 실습 → 확인된 배움 → 후기 링크. 강사가 직접 말하는 듯한 경험담을 비비가 지어내지 않습니다.
- 기술 소개: 어떤 불편을 줄이는지 → 기능·절차 → 구체적인 활용 → 원문. 확인하지 않은 가격·한국 지원·출시 여부를 단정하지 않습니다.
- 모집 홍보: 누구를 위한 과정인지 → 배우는 것 → 확인된 일정·비용·조건 → 신청 URL. 지난 모집 일정은 그대로 재사용하지 않습니다.
- 기사 소개: 공개 제목 → 핵심 변화 → 적용 조건·예외 → 기사 링크. 생성 장면이면 “이미지는 AI로 만든 설명용 연출입니다.”처럼 실제 제작 방식에 맞춰 밝힙니다.

## 같은 입력을 다르게 구성하는 예

입력 사실: 가상 예시인 ‘샘플 교육’에서 AI 문구 다듬기와 포스터 시안 비교를 실습했습니다. 만족도·수강 인원·성과 수치는 없습니다.

Threads 본문 예: “AI가 만든 첫 문구를 그대로 쓰고 계신가요? 샘플 교육에서는 문구를 다듬고 포스터 시안을 비교하며, 목적에 맞는 결과를 고르는 과정을 실습했습니다.”

Instagram 본문 예: “AI로 만든 초안을 실제 홍보물로 완성하는 과정. 이번 카드에는 문구 다듬기 → 시안 비교 → 최종 선택 흐름을 정리했습니다.”

위 예시는 가상 설명이며 실제 강의 후기나 게시 결과가 아닙니다.
