# 게시·예약·검증

문안·카드 제작 요청만 있으면 파일과 캡션을 전달합니다. 공개 또는 예약은 현재 대화의 해당 게시 지시가 있을 때 실행하며, 이미 명시된 권한을 반복해서 묻지 않습니다.

1. 채널·로그인 계정·원문 URL·제목·시간을 맞춥니다. 원문 URL과 같은 소재가 기존 공개·예약 목록에 있는지 조회해 중복을 막습니다. 과거 다른 작업의 미완료 배포는 재개하지 않습니다.
2. 사진 공유인지 카드뉴스인지 구분합니다. 카드뉴스는 `01.png`부터 전체 장을 순서대로 첨부하고 작성창에서 각 장을 확인합니다. 후기 사진 공유는 대표 썸네일과 실제 수업 사진이 별도 파일인지 확인합니다.
3. Instagram은 원본 비율을 유지하고 첫 장·중간·마지막 장의 잘림을 확인합니다. 정사각형 패딩이나 강제 크롭으로 바꾸지 않습니다. 별도 지시가 없으면 Threads 자동 공유를 끕니다.
4. 최종 글자 수·해시태그·첨부 수·링크·AI 이미지 표시·대체 텍스트 설정을 현재 UI 기준으로 확인합니다. AI 주제의 Threads 게시에서 계정 운영 기준이 `AI Threads`를 요구하면 실제 주제 선택을 확인합니다. 무관한 강의에 강제하지 않습니다.
5. 현재 요청이 허용한 공개/예약을 한 번 수행합니다. 사용자에게 알릴 예약 시각은 지정 시간대(모두잇은 기본 Asia/Seoul)로 기록합니다. 클릭 후 시간 초과가 나면 실제 게시·예약 존재부터 조회하고 없는 것이 확인될 때만 재시도합니다.
6. 공개 상세 URL을 다시 열어 계정·본문·첫 인사·원문 링크·모든 이미지의 순서와 잘림을 확인합니다. 예약은 목록의 시각·문안·이미지를 확인하고 예약 완료로 보고합니다. 예약 시각이 지났다는 이유만으로 공개 완료로 바꾸지 않습니다.

보고 항목: 채널 / 계정 / 초안·예약·공개·실패·미확인 / 이미지 장수·규격 / 공개 URL 또는 예약 시각 / 검수 근거 / 남은 일.

기존 게시물 교체는 새 글의 정상 공개를 확인한 후 현재 요청이 허용한 경우에만 기존 글을 처리합니다. 이 스킬은 삭제 권한을 자동 부여하지 않습니다. 계정 연결이나 브라우저 기능이 없으면 제작을 끝내고 게시가 남았다고 정확히 보고합니다.
