# 카드뉴스 제작 기준

## 스타일 선택

최근 사용자가 승인한 시안·참고 이미지가 있으면 아래 기본값보다 우선합니다. 특정 캠페인의 로고·일정·장수를 다른 주제로 복사하지 않습니다.

| 용도 | 스타일 | 구성 기본값 |
| --- | --- | --- |
| 모두잇 강의·기술·홍보 | `modooit`: 짙은 보라, 큰 흰 한글, 초록 강조, 넓은 상단 이미지와 일정한 하단 표기 | 6~8장 권장, 내용·현재 요청에 따라 조절 |
| AI퍼블릭저널 기사 | `wine`: 풀블리드 장면, 하단 와인 #3A1428 그라데이션, 흰 한글, 핑크 #FF4D9D 강조 | 기본 5장: 표지 / 변화 / 대상·조건 / 확인점 / 원문 안내 |
| 밝은 종이 디자인 요청 | `paper`: 크림 #F3EEE6, 테라코타 #C96F4A, 진한 갈색 한글 | 한 장 한 메시지, 글과 여백 중심 |

인스타그램 카드 묶음은 기본 1080×1350 PNG입니다. 블로그의 1:1 대표 썸네일과 구분합니다. Threads도 동일 이미지를 쓸 수 있지만 최종 작성창에서 첨부 순서와 표시를 확인합니다.

## 원고와 시각 자료

- 제목은 통상 2줄, 설명은 짧은 2~3줄을 출발점으로 하되 내용과 레이아웃을 봅니다. 자동 축소로 작은 글씨를 만들기보다 문장을 고칩니다.
- 모두잇은 표지 → 문제 → 해결·활용 → 실습·근거 → CTA 흐름에서 필요한 장을 고릅니다. 없는 후기·강사 경력·신청 조건을 빈칸 채우듯 만들지 않습니다.
- 기사 표지에는 공개 기사 제목을 정확히 넣습니다. 원문·캡션·이미지의 숫자·범위·시점이 일치해야 합니다.
- 배경은 핵심 인물·사물이 상단에 보이게 배치하고 아래 텍스트 자리를 확보합니다. 사진·스크린샷·실습 결과를 무관한 장식 이미지로 바꾸지 않습니다. 실존 기관·인물·제품 화면을 임의로 그려 실제 기록처럼 제시하지 않습니다.
- 계정·브랜드·문의 링크는 현재 프로필에서 가져옵니다. 기본 브랜드 문자열도 다른 사용자는 교체합니다. QR은 검증된 경우에만 붙입니다.

## 포함된 렌더러

이 스킬 폴더에서 Node.js와 npm을 사용할 수 있는지 확인한 뒤 실행합니다.

```sh
npm install
npx playwright install chromium
node scripts/render.mjs examples/spec.json /원하는/출력폴더
```

`package.json`의 Playwright 버전으로 검증했습니다. 설치가 제한된 환경에서는 허용된 기존 Playwright 모듈 경로를 `SOCIAL_PLAYWRIGHT_MODULE`에, 기존 Chrome 실행 파일을 `SOCIAL_CHROME`에 지정할 수 있습니다. macOS 고정 경로에 의존하지 않습니다. 한글 글꼴은 시스템의 Noto Sans KR·맑은 고딕·Apple SD Gothic Neo 중 사용 가능한 것을 쓰므로 환경에 따라 자간이 달라질 수 있습니다.

`examples/spec.json`을 작업 폴더로 복사해 원고를 수정합니다. `image`는 spec 파일 기준 상대경로, `imagePosition`은 `center top` 등 CSS object-position 값입니다. `font`에 사용 가능한 한글 글꼴 이름을 지정할 수 있습니다. `qr`은 `{ "image": "qr.png", "caption": "원문 보기" }`이며 QR 파일 자체는 별도로 생성·디코딩 검증합니다.

출력은 `01.png`부터 순서대로, 미리보기 `index.html`, 기계 검수 `qa.json`입니다. `qa.json`에 글자 겹침·카드 밖 영역·미로딩 이미지 문제가 있으면 실패 코드로 종료합니다. 모든 PNG를 직접 확인해야 합니다. 실행 예시는 기능 검증용 텍스트 카드이며, 실제 게시용으로는 해당 주제의 이미지와 원문을 넣습니다.

## 최종 검수

전체 장수·순서·1080×1350 크기, 표지와 마지막 장, 정확한 제목·사실, 모바일 가독성, 텍스트 겹침·잘림, 사진 적합성, 링크·QR을 확인합니다. 제작 파일·검수용 미리보기·SNS 공개 게시를 별도 상태로 보고합니다.
