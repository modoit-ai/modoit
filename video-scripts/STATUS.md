## v5 수정 내용 (2026-09-27 보스 피드백)

1. **목소리**: 보스가 새로 녹음한 샘플로 「보스 목소리 아나운서톤 (박옥경)」 등록 (voice_id `9cf4299d-62e7-44e7-b9ed-2fac64bc2b52`). 비교 시험 6번 채택 = 음높이 +1, 속도 2, 음량 3 + 음색 보정(맑고 밝게)
2. **문장 끝 내리기**: 끝이 올라가던 물음표·'~죠' 문장 11개를 서술형으로 (예: "있으시죠?" → "있으실 거예요.")
3. **장면 전환 공백 2초 통일**: 모든 장면 사이 말 끝 → 다음 말 시작 2.0초 (인트로 '한 문장 차이' 뒤 3.9초 → 2초)
4. **조사 앞 쉼 삭제**: whisper 단어 위치로 쉼이 대본의 어디인지 판별 → 띄어쓰기 없는 곳(단어와 조사 사이)의 쉼 삭제, 문장 끝 0.42초·쉼표 0.28초·띄어쓰기 0.12초까지만. 0.13초 미만(받침·파열음 멈춤)은 건드리지 않음
5. **말 빠르기 균형**: 구절마다 초당 음절 수를 재서 전체 중앙값(5.6음절/초) 쪽으로 ±10% 이내 보정(음높이 유지)
6. **끊김 방지**: 자르는 지점은 항상 무음 한가운데, 문장별 음량 맞춤 후 믹스
7. **화면 싱크**: 핵심 4가지 체크, 역할·상황·요청·형식 강조, 구독·좋아요·알림 버튼을 실제 단어가 들리는 시각에 맞춤
8. **강사 장면(임시)**: 입모양 영상 대신 강사 사진 + 아주 느린 줌. B안(새 목소리 립싱크, 약 210크레딧)으로 바꾸면 그 장면만 교체

## v4 수정 내용 (2026-09-27 보스 피드백)

1. **끝부분 순서 변경**: 댓글 요청 → **오늘의 핵심 4가지** 정리 (목록이 말에 맞춰 하나씩 등장) → 수정쌤 인사 → 공통 아웃트로
2. **공통 아웃트로 모션그래픽 (약 22초)**: 설명란 링크 안내 → 구독·좋아요·알림 버튼을 손가락이 차례로 누름 → "미래 교육은 모두잇 수정쌤과 함께" 인사. 모든 영상 끝에 그대로 붙이도록 따로 파일로도 저장 (`outro/README.md`)
3. **소리 튐 수정**: 최종 인코딩에서 순간 피크가 0dB를 넘던 문제 → 리미터 0.6, AAC 256k로 바꿔 피크 -3.1 dBFS
4. 앞부분(0~9분 30초)은 v3 화면 그대로, 뒷부분만 다시 렌더

## v3 수정 내용 (2026-09-27 보스 피드백)

1. **강사 장면**: 사진 600→440px로 줄이고 글자 92→124px로 키움. 사진+글자를 한 묶음으로 장면마다 폭을 재서 화면 정중앙 배치
2. **단락 전환 여유**: 챕터가 바뀌면 화면이 먼저 나오고 약 2.2초 뒤 내레이션 (배경음악이 그 사이 살짝 올라옴)
3. **프롬프트 읽을 시간**: 말이 끝난 뒤 추가로 화면 유지 — 프롬프트 +4초, 직군별 예시 +4.5초, 비교 화면 +2.5초, 비교표 +3초, 대화 +1.5초. 타이핑은 말이 끝나기 전에 완성
4. **더듬·끊김 수정**: whisper로 50개 문장 전사·쉼 분석 → 원인은 쉼표·따옴표에서 엔진이 끊는 것. 슬라이드 내레이션 40문장을 쉼표를 줄여 다시 생성하고, 문장 중간 0.5초 넘는 쉼은 0.38초로 정리. 재검사에서 엔진이 문장 앞에 없는 말을 지어낸 02c, 끝을 잘못 읽은 05f, 발음이 애매한 01e를 한 번 더 생성해 전사 일치 확인. 강사 립싱크 문장 9개는 원래 깨끗해서 유지
5. **설명란 블로그 링크 안내**: 인사 직후 "오늘 안내해 드리는 프롬프트는 영상 설명란에 있는 블로그 링크로…" 장면 추가, 마지막 안내도 블로그 링크로 변경
6. **배경음악**: ChatCut을 클라우드에서 쓸 수 없어 `production/v3/bgm.py`로 저작권 걱정 없는 연주곡을 직접 합성 (90BPM 패드·일렉피아노·베이스·가벼운 퍼커션). 스킬 확정 레벨 적용: 목소리 아래 0.09, 인트로 0.20, 마무리 0.22, 단락 전환 쉼 0.15
