# [모두잇 AI 교실] AI에게 말 잘 거는 법: 프롬프트 활용법

- **대상**: AI를 처음이거나 막 써보기 시작한 분 (시니어, 디지털 입문자, 소상공인)
- **길이**: 약 6~7분 (내레이션 기준 1분에 약 250자)
- **톤**: 다정하고 천천히. 전문용어는 반드시 쉬운 말로 한 번 더 풀어서 말하기
- **구성**: 오프닝 → 프롬프트란? → 좋은 프롬프트 4가지 재료 → 챗 vs 에이전트 → 꼭 기억할 주의점 → 마무리

---

## #1. 오프닝 (0:00~0:30)

| 화면 | 내레이션 | 자막 |
|---|---|---|
| 스마트폰으로 AI에게 "글 써줘"라고 입력하는 손. 엉뚱한 답이 나와 갸우뚱하는 어르신 | AI한테 물어봤는데, 내가 원하는 답이 안 나온 적 있으시죠? | 원하는 답이 안 나온 적, 있으시죠? |
| 같은 분이 다시 입력하자 딱 맞는 답이 나와 활짝 웃음 | 그건 여러분 잘못이 아니에요. **말 거는 방법**을 조금만 바꾸면, AI는 훨씬 똑똑한 비서가 됩니다. | 말 거는 방법만 바꾸면 됩니다 |
| 타이틀 카드: 모두잇 로고 + "AI에게 말 잘 거는 법" | 오늘은 모두잇과 함께, 프롬프트 활용법을 배워볼게요. | AI에게 말 잘 거는 법 — 프롬프트 활용법 |

## #2. 프롬프트란? (0:30~1:10)

| 화면 | 내레이션 | 자막 |
|---|---|---|
| 채팅창 입력칸이 확대되며 반짝임 | 프롬프트는 어려운 말이 아니에요. AI에게 보내는 **부탁의 말**, 바로 이 입력창에 쓰는 글이 프롬프트입니다. | 프롬프트 = AI에게 하는 부탁의 말 |
| 새로 온 비서에게 쪽지로 일을 맡기는 장면 | AI는 오늘 처음 출근한 아주 똑똑한 신입 비서라고 생각해 보세요. 똑똑하지만, 나에 대해서도, 내 상황에 대해서도 아무것도 몰라요. | AI = 똑똑하지만 나를 모르는 신입 비서 |
| "글 써줘" 쪽지 → 비서가 난감한 표정 | 그래서 "글 써줘"라고만 하면, 무슨 글을, 누구에게, 얼마나 써야 할지 모르는 거죠. | 짧게 말하면, AI는 짐작할 수밖에 없어요 |

## #3. 좋은 프롬프트의 4가지 재료 (1:10~3:00)

| 화면 | 내레이션 | 자막 |
|---|---|---|
| 요리 재료 4개가 도마 위에 놓이는 그래픽: ① 역할 ② 상황 ③ 요청 ④ 형식 | 맛있는 요리에 재료가 필요하듯, 좋은 프롬프트에도 네 가지 재료가 있어요. **역할, 상황, 요청, 형식**입니다. | 좋은 프롬프트 = 역할 + 상황 + 요청 + 형식 |
| ① 역할 카드 | 첫째, **역할**. "너는 친절한 동네 꽃집 사장님이야"처럼 AI에게 누가 되어 달라고 알려주세요. | ① 역할: "너는 ○○야" |
| ② 상황 카드 | 둘째, **상황**. "어버이날을 앞두고, 단골 손님들께 안부 문자를 보내려고 해"처럼 왜 필요한지 알려주세요. | ② 상황: 왜, 누구에게 |
| ③ 요청 카드 | 셋째, **요청**. "따뜻한 안부 문자를 써줘"처럼 무엇을 해달라는지 분명하게요. | ③ 요청: 무엇을 해줘 |
| ④ 형식 카드 | 넷째, **형식**. "세 줄 이내로, 존댓말로, 이모티콘은 한 개만"처럼 결과 모양을 정해주세요. | ④ 형식: 길이, 말투, 모양 |
| Before/After 분할 화면. 왼쪽 "문자 써줘" → 딱딱한 문장 / 오른쪽 4가지 재료 프롬프트 → 따뜻한 문장 | 같은 AI인데도, 재료를 넣었을 때 결과가 이렇게 달라집니다. | 재료를 넣으면 결과가 달라져요 |
| 화면 하단에 완성 프롬프트 전체 표시 | 한번 따라 해 보세요. "너는 친절한 동네 꽃집 사장님이야. 어버이날을 앞두고 단골 손님들께 안부 문자를 보내려고 해. 따뜻한 안부 문자를 써줘. 세 줄 이내, 존댓말, 이모티콘은 하나만." | (완성 프롬프트 예시 전체 자막) |
| ⭐ 보너스 카드: "예시 보여주기" | 보너스 팁! 원하는 느낌의 **예시**를 하나 붙여주면 AI가 훨씬 잘 알아들어요. "이런 느낌으로 써줘" 하고요. | 보너스: 예시를 보여주면 더 정확해요 |

## #4. 챗 vs 에이전트: 부탁하는 방법도 달라요 (3:00~5:00)

| 화면 | 내레이션 | 자막 |
|---|---|---|
| 화면 반으로 나뉨. 왼쪽 "챗 💬" 말풍선 / 오른쪽 "에이전트 🤖" 일하는 로봇 | 요즘 AI에는 두 가지 모드가 있어요. 대화를 나누는 **챗**, 그리고 일을 직접 해주는 **에이전트**입니다. | 챗 = 대화 상대 / 에이전트 = 일 대신 해주는 비서 |
| 챗: 사람과 AI가 말풍선을 주고받음 | **챗**은 물어보면 말로 대답해 주는 상담 선생님 같아요. 답을 읽고, 실제로 행동하는 건 나예요. | 챗: 답을 "알려줘요" |
| 에이전트: AI가 웹 검색 → 표 정리 → 파일 저장까지 스스로 진행하는 장면 | **에이전트**는 심부름을 맡기는 비서예요. 검색하고, 정리하고, 파일로 만드는 일까지 여러 단계를 스스로 해냅니다. | 에이전트: 일을 "해줘요" |
| 비교표 그래픽 (아래 표 참고) | 그래서 부탁하는 방법도 조금 달라요. | 부탁하는 방법이 달라요 |
| 챗 예시 프롬프트 타이핑 | 챗에서는 **질문을 구체적으로** 하는 게 핵심이에요. "우리 동네 복지관 스마트폰 교실 홍보 문구 세 가지만 추천해 줘." 마음에 안 들면 "더 짧게", "더 따뜻하게" 하고 대화로 다듬으면 돼요. | 챗: 구체적으로 묻고, 대화로 다듬기 |
| 에이전트 예시 프롬프트 타이핑 | 에이전트에게는 **일을 맡기는 지시서**처럼 써야 해요. 목표가 무엇인지, 다 끝나면 어떤 모습이어야 하는지, 그리고 **하지 말아야 할 것**까지요. | 에이전트: 목표 + 완성 모습 + 하지 말 것 |
| 에이전트 프롬프트 전체 표시 | 예를 들면 이렇게요. "다음 달 우리 구에서 열리는 무료 디지털 교육을 찾아서 표로 정리해 줘. 날짜, 장소, 신청 방법을 꼭 넣고, 공식 기관 홈페이지 정보만 사용해 줘. 신청이나 결제는 하지 말고, 하기 전에 나에게 먼저 물어봐." | (에이전트 프롬프트 예시 전체 자막) |
| "✋ 먼저 물어봐" 스티커가 강조됨 | 특히 에이전트는 실제로 행동을 하기 때문에, **"결제, 전송, 삭제 전에는 꼭 나에게 물어봐"** 이 한마디가 아주 중요해요. | 중요한 일은 "먼저 물어봐" |

**비교표 그래픽 (#4 화면용)**

| | 💬 챗 | 🤖 에이전트 |
|---|---|---|
| 한마디로 | 물어보면 알려주는 상담 선생님 | 일을 맡기면 해내는 비서 |
| 결과 | 답변(글) | 실제 결과물(파일, 표, 검색 정리, 예약 등) |
| 프롬프트 핵심 | 구체적인 질문 + 원하는 형식 | 목표 + 완성 모습 + 허용 범위 + 확인 시점 |
| 잘 쓰는 법 | 여러 번 주고받으며 다듬기 | 처음에 한 번 꼼꼼하게 지시하기 |
| 조심할 점 | 답이 틀릴 수 있으니 확인 | 결제·전송·삭제 전 "먼저 물어봐" |

## #5. 꼭 기억할 3가지 (5:00~6:10)

| 화면 | 내레이션 | 자막 |
|---|---|---|
| 체크리스트 1 ✅ | 첫째, **한 번에 완벽할 필요 없어요.** AI와의 대화는 주고받는 거예요. "좋아, 그런데 조금 더 쉽게" 하고 이어서 말해 보세요. | ① 한 번에 완벽하지 않아도 OK, 대화로 다듬기 |
| 체크리스트 2 ✅ — 돋보기로 답변을 살피는 모습 | 둘째, **AI도 틀릴 수 있어요.** 병원, 돈, 법에 관한 내용은 꼭 공식 기관이나 전문가에게 한 번 더 확인하세요. | ② AI도 틀려요. 중요한 건 꼭 확인! |
| 체크리스트 3 ✅ — 주민번호·통장번호에 자물쇠 아이콘 | 셋째, **개인정보는 넣지 마세요.** 주민등록번호, 통장 비밀번호, 가족 연락처 같은 정보는 AI에 입력하지 않는 게 안전합니다. | ③ 개인정보는 입력 금지 |

## #6. 마무리 (6:10~6:40)

| 화면 | 내레이션 | 자막 |
|---|---|---|
| 4가지 재료 + 챗/에이전트 요약 카드 | 오늘 배운 것 정리해 볼게요. 좋은 프롬프트는 역할, 상황, 요청, 형식. 챗에서는 구체적으로 묻고, 에이전트에게는 지시서처럼 맡기고, 중요한 일은 먼저 물어보게 하기! | 역할·상황·요청·형식 / 챗은 묻고, 에이전트는 맡기기 |
| 다양한 연령대 수강생들이 함께 웃으며 스마트폰을 보는 장면 | AI는 잘하는 사람만 쓰는 도구가 아니에요. 누구나, 조금씩, 편하게 쓸 수 있어요. 디지털 때문에 소외되는 사람이 없도록, 모두잇이 함께하겠습니다. | 누구나 쉽게, 모두잇이 함께합니다 |
| 엔딩: 모두잇 로고, 모두잇 클래스 '프롬프트 모음' 페이지 화면 | 오늘 예시 프롬프트는 모두잇 클래스 '프롬프트 모음'에서 바로 복사해서 써 보세요. | 모두잇 클래스 → 프롬프트 모음에서 복사해 보세요 |

## 제작 메모

- **자막 크기**: 시니어 시청자를 고려해 크게, 한 화면 2줄 이내
- **말 속도**: 평소보다 10~15% 느리게, 예시 프롬프트 읽을 때는 한 번 더 천천히
- **연계**: #3 꽃집 문자 프롬프트, #4 챗/에이전트 예시 프롬프트를 모두잇 클래스 '프롬프트 모음'에 미리 등록해 두기
- **숏폼 분할 가능**: #3(4가지 재료), #4(챗 vs 에이전트), #5(주의점)은 각각 1분 쇼츠로 잘라 쓰기 좋음
