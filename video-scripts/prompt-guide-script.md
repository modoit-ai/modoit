# [모두잇 AI 교실] AI가 내 말을 못 알아듣는 진짜 이유 (딱 한 문장 차이)

- **대상**: AI를 써봤지만 "별로네" 하고 멈춘 분, 아직 제대로 못 쓰는 분 (시니어, 디지털 입문자, 소상공인, 직장인)
- **길이**: 약 12분 (내레이션 기준 1분에 약 250자)
- **진행**: 박옥경 대표강사 (교실 배경 강사 이미지 + 대표 본인 목소리 내레이션)
- **톤**: 다정하고 천천히. 전문용어는 반드시 쉬운 말로 한 번 더 풀어서 말하기
- **기획 방향**: "프롬프트 활용법 강의"가 아니라 **"AI가 내 말을 못 알아듣는 이유와 해결법"**. 기술 이름보다 시청자의 답답함과 결과를 앞세운다. "프롬프트"라는 단어는 제목·썸네일에서 빼고, 본문에서도 "AI에게 하는 부탁의 말"로 풀어서 쓴다
- **구성**: 훅(Before/After) → 강사 인사 → 왜 못 알아듣나? → 4가지 재료 → 내 직업이라면? 예시 5개 → AI가 일을 대신 하는 시대(챗 vs 에이전트) → 이제 외우지 마세요(AI에게 물어보기) → 작년 방식은 안 통해요(유통기한) → 꼭 기억할 3가지 → 마무리 + 댓글 참여

## 업로드 패키지

**제목 후보** (1번 추천)
1. AI가 자꾸 엉뚱한 답을 하는 진짜 이유 | 딱 한 문장 차이
2. ChatGPT한테 이 한 문장만 붙이세요. 답이 완전히 달라집니다
3. 작년에 배운 AI 사용법, 지금은 안 통합니다
4. 이제 AI 명령어 외우지 마세요 (대신 이렇게 하세요)
5. 사회복지사·카페 사장님·강사… 내 직업에 딱 맞는 AI 활용법

**썸네일**
- 왼쪽: 교실 배경 박옥경 대표강사 (살짝 놀란 표정 또는 손가락으로 화면 가리키기)
- 오른쪽: ❌ "글 써줘" → 딱딱한 답 / ⭕ 한 문장 추가 → 따뜻한 답 (Before/After)
- 큰 글씨: **"AI 답이 이상하다면?"** 또는 **"딱 한 문장 차이"** (둘 중 하나만, 10자 안팎)
- "프롬프트"라는 단어는 쓰지 않기

**설명란 첫 줄**: AI한테 물어봤는데 원하는 답이 안 나오셨나요? 여러분 잘못이 아니에요. 딱 한 문장만 바꿔보세요.

**태그**: AI 활용법, ChatGPT 사용법, 제미나이, AI 초보, 시니어 AI, 사회복지사 AI, 소상공인 AI 홍보, 강사 AI 수업자료, AI 에이전트, 모두잇

## #2. AI는 왜 내 말을 못 알아들을까? (0:40~1:20)

| 화면 | 내레이션 | 자막 |
|---|---|---|
| 채팅창 입력칸이 확대되며 반짝임 | 우리가 AI 입력창에 쓰는 글, 이걸 어려운 말로 "프롬프트"라고 해요. 그냥 AI에게 보내는 **부탁의 말**이라고 생각하시면 돼요. | 프롬프트 = AI에게 하는 부탁의 말 |
| 새로 온 비서에게 쪽지로 일을 맡기는 장면 | AI는 오늘 처음 출근한 아주 똑똑한 신입 비서라고 생각해 보세요. 똑똑하지만, 나에 대해서도, 내 상황에 대해서도 아무것도 몰라요. | AI = 똑똑하지만 나를 모르는 신입 비서 |
| "글 써줘" 쪽지 → 비서가 난감한 표정 | 그래서 "글 써줘"라고만 하면, 무슨 글을, 누구에게, 얼마나 써야 할지 모르는 거죠. AI가 엉뚱한 답을 하는 건, **짐작으로 채웠기 때문**이에요. | 엉뚱한 답 = AI가 짐작으로 채운 것 |

## #3. 딱 맞는 답을 부르는 4가지 재료 (1:20~3:10)

| 화면 | 내레이션 | 자막 |
|---|---|---|
| 요리 재료 4개가 도마 위에 놓이는 그래픽: ① 역할 ② 상황 ③ 요청 ④ 형식 | 그럼 짐작하지 않게 하려면 뭘 알려줘야 할까요? 맛있는 요리에 재료가 필요하듯, AI에게 하는 부탁에도 네 가지 재료가 있어요. **역할, 상황, 요청, 형식**입니다. | 역할 + 상황 + 요청 + 형식 |
| ① 역할 카드 | 첫째, **역할**. "너는 친절한 동네 꽃집 사장님이야"처럼 AI에게 누가 되어 달라고 알려주세요. | ① 역할: "너는 ○○야" |
| ② 상황 카드 | 둘째, **상황**. "어버이날을 앞두고, 단골 손님들께 안부 문자를 보내려고 해"처럼 왜 필요한지 알려주세요. | ② 상황: 왜, 누구에게 |
| ③ 요청 카드 | 셋째, **요청**. "따뜻한 안부 문자를 써줘"처럼 무엇을 해달라는지 분명하게요. | ③ 요청: 무엇을 해줘 |
| ④ 형식 카드 | 넷째, **형식**. "세 줄 이내로, 존댓말로, 이모티콘은 한 개만"처럼 결과 모양을 정해주세요. | ④ 형식: 길이, 말투, 모양 |
| Before/After 분할 화면. 왼쪽 "문자 써줘" → 딱딱한 문장 / 오른쪽 4가지 재료 프롬프트 → 따뜻한 문장 | 같은 AI인데도, 재료를 넣었을 때 결과가 이렇게 달라집니다. | 재료를 넣으면 결과가 달라져요 |
| 화면 하단에 완성 프롬프트 전체 표시 | 한번 따라 해 보세요. "너는 친절한 동네 꽃집 사장님이야. 어버이날을 앞두고 단골 손님들께 안부 문자를 보내려고 해. 따뜻한 안부 문자를 써줘. 세 줄 이내, 존댓말, 이모티콘은 하나만." | (완성 프롬프트 예시 전체 자막) |
| ⭐ 보너스 카드: "예시 보여주기" | 보너스 팁! 원하는 느낌의 **예시**를 하나 붙여주면 AI가 훨씬 잘 알아들어요. "이런 느낌으로 써줘" 하고요. | 보너스: 예시를 보여주면 더 정확해요 |

## #5. 이제 AI가 일을 대신 해줍니다: 챗 vs 에이전트 (5:40~7:40)

| 화면 | 내레이션 | 자막 |
|---|---|---|
| 화면 반으로 나뉨. 왼쪽 "챗 💬" 말풍선 / 오른쪽 "에이전트 🤖" 일하는 로봇 | 요즘 AI는 대답만 하는 게 아니에요. **일을 직접 해주기** 시작했어요. 그래서 AI에는 두 가지 모드가 있어요. 대화를 나누는 **챗**, 그리고 일을 직접 해주는 **에이전트**입니다. | 챗 = 대화 상대 / 에이전트 = 일 대신 해주는 비서 |
| 챗: 사람과 AI가 말풍선을 주고받음 | **챗**은 물어보면 말로 대답해 주는 상담 선생님 같아요. 답을 읽고, 실제로 행동하는 건 나예요. | 챗: 답을 "알려줘요" |
| 에이전트: AI가 웹 검색 → 표 정리 → 파일 저장까지 스스로 진행하는 장면 | **에이전트**는 심부름을 맡기는 비서예요. 검색하고, 정리하고, 파일로 만드는 일까지 여러 단계를 스스로 해냅니다. | 에이전트: 일을 "해줘요" |
| 비교표 그래픽 (아래 표 참고) | 그래서 부탁하는 방법도 조금 달라요. | 부탁하는 방법이 달라요 |
