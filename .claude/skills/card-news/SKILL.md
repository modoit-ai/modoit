# 카드뉴스 만들기

주제나 원문을 받아 **① 기획 → ② 원고(JSON) 작성 → ③ 렌더링 → ④ 검수 → ⑤ 전달** 순서로 인스타그램 카드뉴스를 만든다.

## 1. 기획

요청에서 아래 항목을 파악한다. 빠진 부분은 합리적인 기본값으로 채우고, 꼭 필요할 때만 질문한다.

| 항목 | 기본값 |
|---|---|
| 목적 | 정보 전달 + 교육 신청 유도 |
| 대상 | 디지털이 낯선 어르신·일반 시민 (모두잇의 핵심 대상) |
| 장수 | 6~8장 (표지 1 + 본문 4~6 + 마무리 1) |
| 테마 | `modoit` |
| 말투 | 다정한 존댓말("~해요") |

**구성 흐름 (훅 → 공감 → 해결 → 행동)**
1. `cover` — 스크롤을 멈추게 하는 제목. 숫자·질문·반전 활용 ("~하는 5가지 방법", "아직도 ~하세요?")
2. `stat` / `point` — 왜 알아야 하는지, 공감 한 장
3. `list` / `steps` / `compare` — 핵심 내용 (한 장에 메시지 하나)
4. `quote` — 수강생 후기·전문가 한마디 (신뢰)
5. `closing` — 행동 유도(CTA): 교육 신청, 저장, 공유

## 2. 원고 작성 규칙 (가독성 = 모두잇의 가치)

- **한 장에 메시지 하나.** 넘치면 두 장으로 나눈다.
- 제목은 2~3줄, 한 줄 12자 안팎. 줄바꿈은 `\n`으로 직접 지정한다(의미 단위로).
- `list`는 최대 5개, `steps`는 최대 4개, `compare`는 한쪽 최대 4개.
- 각 항목 제목은 15자, 설명은 25자 이내.
- 어려운 용어(앱, QR, 인증서 등)는 쉬운 말로 풀어 쓴다.
- 통계를 쓰면 반드시 실제 출처를 `source`에 적는다. 확인할 수 없는 수치는 지어내지 말고, 사용자에게 확인을 요청하거나 "예시"라고 표기한다.
- 후기·인용은 사용자가 준 실제 문장만 쓴다. 없으면 "(예시)"를 붙여 사용자가 교체하도록 알린다.

**강조 문법** (모든 텍스트 필드)
- `**형광펜**` → 노란 밑줄 형광펜
- `==포인트색==` → 테마 포인트 색 글자 (표지·마무리에서는 노란색)

## 3. 원고 JSON 형식

`examples/kiosk-tips.json`을 참고한다. 작업 폴더(예: 스크래치패드나 `card-news/<slug>/`)에 `spec.json`으로 저장한다.

```json
{
  "title": "게시물 제목",
  "slug": "output-folder-name",
  "theme": "modoit",
  "series": "상단 태그 기본 문구(선택)",
  "brand": { "name": "모두잇미래교육진흥협회", "handle": "@modoit", "logo": "<저장소>/images/logo.png" },
  "colors": { "accent": "#7C3AED" },
  "slides": [ { "layout": "cover", ... } ]
}
```

- `logo` 경로는 **spec.json 파일 기준 상대경로** 또는 절대경로. 모두잇 로고는 저장소의 `images/logo.png`.
- `colors`로 테마 색을 부분 덮어쓰기 가능: `bg, soft, ink, sub, accent, accent2, coverBg, coverInk, hl`.
- 테마: `modoit`(보라, 기본) · `warm`(주황) · `mint`(초록) · `navy`(남색) · `dark`(다크 보라)

### 레이아웃별 필드

| layout | 필드 | 용도 |
|---|---|---|
| `cover` | `kicker`, `title`, `subtitle`, `image`(배경사진, 선택) | 표지 |
| `point` | `tag`, `emoji`, `title`, `body`, `image` | 큰 메시지 한 문장 |
| `list` | `tag`, `title`, `items[]` (문자열 또는 `{title, desc}`) | 번호 목록 |
| `steps` | `tag`, `title`, `items[]` (`{title, desc}`) | 따라 하기 단계 |
| `compare` | `tag`, `title`, `left{label, items[]}`, `right{label, items[]}`, `body` | ✕ vs ✓ 비교 |
| `quote` | `tag`, `quote`, `by` | 후기·인용 |
| `stat` | `tag`, `title`, `value`, `unit`, `body`, `source` | 숫자 강조 |
| `closing` | `title`, `body`, `cta` | 마무리·행동 유도 |

모든 본문 슬라이드에는 상단 태그·페이지 번호(03 / 07), 하단 로고·계정·"넘겨보기 →"가 자동으로 붙는다.

## 4. 렌더링

```bash
node .claude/skills/card-news/scripts/render.mjs <spec.json> [출력폴더]
```

- 출력: `index.html`(전체 미리보기) + `01.png`, `02.png` … (각 1080×1350)
- Playwright(전역 설치)와 `/opt/pw-browsers/chromium`을 자동으로 찾는다. 로컬 PC라면 `npm i -g playwright && npx playwright install chromium`.
- 폰트: Google Fonts의 Noto Sans KR. 불러오지 못하면 경고가 뜬다.
- 내용이 넘치면 자동으로 글자를 줄이고 `ⓘ n번 슬라이드 90%로 축소`처럼 알려 준다. **85% 미만으로 줄었다면 원고를 줄이거나 슬라이드를 나눠서 다시 렌더링한다.**

## 5. 검수 (반드시)

렌더링 후 PNG를 Read 도구로 직접 열어 확인한다.
- 글자가 헤더·푸터와 겹치거나 잘리지 않았는가
- 한 단어가 어색하게 다음 줄로 넘어가지 않았는가 → `\n` 위치 조정
- 강조가 한 장에 1~2곳 이하인가 (너무 많으면 강조가 아니다)
- 맞춤법, 기관명(모두잇미래교육진흥협회), 연락처·링크가 정확한가
- 어르신이 휴대폰에서 읽기에 글자가 충분히 큰가

## 6. 전달

- PNG 파일들을 사용자에게 보낸다 (SendUserFile 등). 인스타그램에는 01부터 순서대로 올리면 된다.
- 함께 **게시물 캡션**을 작성해 준다: 첫 줄 훅 1문장 → 핵심 요약 3줄 → 신청/문의 안내 → 해시태그 10~15개 (#디지털교육 #어르신스마트폰교육 #디지털튜터 #모두잇 #모두잇미래교육진흥협회 등).
- 수정 요청이 오면 spec.json만 고쳐 다시 렌더링한다.

## 새 스타일 맞추기

사용자가 참고 게시물(스크린샷)을 주면 색상·배경·강조 방식을 관찰해 `colors`로 맞추고, 구조가 다르면 `scripts/render.mjs`의 `THEMES`에 새 테마를 추가하거나 `L`에 새 레이아웃을 추가한다.
